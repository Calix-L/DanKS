# Security Policy

## Supported scope

Security fixes are accepted for repository tooling and the code snapshots currently present on the default branch. Historical generation behavior may be preserved for reproducibility, so a fix can be documented instead of backported when compatibility would be broken.

## Reporting a vulnerability

Please report vulnerabilities privately to the repository owner or through the private security-reporting channel configured by the eventual hosting platform. Do not include credentials, private endpoints, model files, internal documents, or production data in a public issue.

Include the affected path, impact, reproduction steps using synthetic data, and a proposed mitigation if available. Maintainers will acknowledge a complete report after it reaches the private channel.
